1. `/CLAUDE.md` を読んでプロジェクトの基本情報を把握
2. `/docs/figma-guide/figma-common-guide.md` を読んで共通要件を把握
3. `/docs/figma-guide/figma-page-guide.md` を読んでページ固有要件を把握
4. `/docs/responsive-style-guide.md` を読んでレスポンシブの書き方を把握
